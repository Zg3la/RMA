# MotoGP Fantasy

MotoGP Fantasy is an Android fantasy racing app built with Kotlin and Jetpack Compose.

## Features

- Google sign-in with Firebase Authentication
- MotoGP fantasy team builder
- Rider and constructor selection
- Budget tracking
- League creation and joining with codes
- Public and private leagues
- Leaderboards
- Race calendar and results
- User profile and notification preferences

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Firebase Authentication
- Firebase Firestore
- Firebase Cloud Messaging
- Hilt
- Retrofit
- Gradle Kotlin DSL
